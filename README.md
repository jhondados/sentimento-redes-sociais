# 📣 Social Listening & Sentimento

> Monitoramento de marca em redes sociais com NLP em tempo real. Analisa sentimento PT-BR, detecta crises e identifica tendências emergentes.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/sentimento-redes-sociais/

## 📊 Resultados-chave (KPIs)
**28M** Posts/dia · **0.94** F1 PT-BR · **< 3min** Alerta crise · **12** Marcas

## 🧠 Tecnologias de IA
NLP · Sentiment · BERTimbau · Real-time

## ✨ O que faz
- Sentimento PT-BR em tempo real
- Detecção de crise (< 3min)
- Análise de concorrência
- Identificação de influenciadores

## 🗄️ Fonte de dados real
[Redes sociais + notícias](https://www.gov.br)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Redes sociais + notícias
2. **Processamento com IA** — NLP · Sentiment · BERTimbau · Real-time
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
